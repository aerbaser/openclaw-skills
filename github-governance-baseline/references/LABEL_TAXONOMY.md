
# Label Taxonomy

Keep labels small and routing-oriented.

## Core labels
- bug
- enhancement
- refactor
- ci
- docs
- tech-debt
- security
- blocked
- breaking-change
- infrastructure

## Optional area labels
Only if the repo actually uses them:
- frontend
- backend
- auth
- billing
- api
- data

## Anti-patterns
- 40 one-off labels
- labels nobody uses in triage
- labels duplicating project names or obvious nouns
