
# Repo Baseline

Every managed repo should have:

- description
- meaningful topics
- README with purpose / setup / commands / owner
- CI
- CODEOWNERS
- issue / PR intake path
- dependency hygiene
- ruleset or branch protection target state

## Template repos
Template repos should additionally have:
- intentionally generic README
- starter CI or stub CI
- obvious placeholders
- ownership and update policy

## Forks
Intentional forks should have:
- description explaining why the fork exists
- upstream reference
- clear statement whether patches are expected or it is mirror-only

## Labs
Labs should have:
- one-line description
- owner
- explicit expiration or review intent if possible

## Parking repos
Parking repos should be promoted, archived, or deleted.
They should not silently accumulate.
