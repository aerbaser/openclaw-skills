
# Delivery Format

Every platform-steward run should return these sections.

## 1. Mode selected
State the chosen mode and why it fits.

## 2. Scope
List:
- owner / org
- repositories in scope
- whether this was audit or apply

## 3. Work performed
List child skills used and their order.

## 4. Findings
Split into:
- safe findings
- risky findings
- blockers

## 5. Changes made
Exact files, settings, or repos changed.

## 6. Approval-required actions
Separate section for:
- archive
- delete
- rename
- transfer
- visibility
- org-level rules

## 7. Next 10 actions
Ordered list.
Fast wins first.
Risky or permission-bound work later.
