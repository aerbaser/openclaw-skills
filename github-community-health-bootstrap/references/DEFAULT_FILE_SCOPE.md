
# Default File Scope

Use the public `.github` repository for shared defaults.

Put in the shared repo:
- CONTRIBUTING.md
- CODE_OF_CONDUCT.md
- SECURITY.md
- SUPPORT.md
- issue forms or templates
- PR template

Use repo-local overrides only when the shared defaults are wrong for that repo.

## Good use cases for local overrides
- special support channel
- unusual contributor workflow
- repo-specific issue intake that the shared form cannot express cleanly

## Bad use cases for local overrides
- copying the same template into every repo
- changing wording for no operational reason
- making the shared baseline irrelevant
