# Agent Rules — openclaw-tools (Skills Repo)

## Branch & PR
- Never rename the branch after spawn. AO tracks branch by original name.
- One issue = one branch = one PR.
- Branch naming: `issue-<number>-<short-slug>`.

## Code Quality
- Before every push: verify all Python scripts compile (`python3 -c "import ast; ast.parse(open('file').read())"` for each .py).
- Use conventional commits. Reference the issue number in every commit.
- Do not touch unrelated skill directories.

## Scope
- This is a skills/instructions repo. No runtime services, no servers.
- Do not modify: `~/.openclaw/openclaw.json` (that's the gateway config, not here).
- Skill structure: each skill = directory with SKILL.md at root.
- Do not add skills that require external API keys without documenting them in SKILL.md.

## When Stuck
- If blocked for >10 min — post a clear blocker description. Do not invent solutions.
