
# Dependabot Policy

## Baseline
Use Dependabot for:
- dependency version updates where useful
- security updates where available
- GitHub Actions update hygiene where workflows rely on actions

## Keep it manageable
- group related ecosystems when noise would otherwise be excessive
- avoid daily noise for quiet repos
- tune schedule based on repo criticality

## Fork note
Do not assume a fork should inherit the same baseline without checking whether the fork is intentional and active.
