# Operating Model

The GitHub platform is clean only when these are true:

1. every repository has a class;
2. every class has an action;
3. every live repo has a baseline;
4. every work item is handed off through an execution-grade issue.

## Portfolio cleanup order

1. inventory
2. classification
3. action plan
4. archive/delete dry-run
5. `.github` defaults
6. managed repo hardening
7. ongoing maintenance

## Managed repo minimum bar

- description
- topics
- README
- CI
- CODEOWNERS
- PR template
- issue template or org default
- Dependabot
- security baseline
