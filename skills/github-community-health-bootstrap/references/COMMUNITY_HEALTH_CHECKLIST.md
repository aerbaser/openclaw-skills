
# Community Health Checklist

## Minimum shared baseline
- README for the `.github` repo itself
- CONTRIBUTING
- CODE_OF_CONDUCT
- SUPPORT
- SECURITY
- bug form
- feature form
- task form
- PR template

## Good defaults
- link SUPPORT from README if useful
- make the issue form chooser explicit
- discourage using issues for support if there is a better support channel

## Avoid
- giant essays no contributor will read
- forms with 20 fields
- duplicate instructions across every file
