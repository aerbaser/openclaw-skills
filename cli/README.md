# CLI Tools

Agent utility scripts used by Sokrat and sub-agents.

## Tools

| Script | Description |
|--------|-------------|
| perplexity-search.sh | Deep research via Perplexity API |
| webhook-receiver.js | HTTP webhook → system event bridge |
| credential-share.js | One-time credential share via Vaultwarden |

## Source
Scripts live in `~/clawd/scripts/`. This dir tracks the *published* versions.
To sync: `cp ~/clawd/scripts/<tool> ~/.openclaw/skills/cli/`
